# Coffee Roasting Cheatsheet

## Gene Cafe CB-101 Notes
- Temperature display shows **air temperature**, not bean temperature
- Typical batch size: 200–250g green beans
- Allow machine to return to charge temp between back-to-back roasts

---

## The Three Phases

### Phase 1 — Drying (30–45% of total roast time)
| | Detail |
|---|---|
| Temp range | Ambient → ~300°F (150°C) |
| Color | Green → pale yellow |
| Aroma | Grassy → hay → faint sweetness |
| Bean state | Endothermic (absorbing heat); moisture evaporating |

**Watch for:** Full yellow color signals drying is complete. Don't rush this phase.
**Defect risk:** Too fast = scorched beans (harsh, grassy cup). Too slow = baked beans (papery, flat cup).

---

### Phase 2 — Browning / Maillard (35–45% of total roast time)
| | Detail |
|---|---|
| Temp range | ~300°F → ~385°F (150°C → 196°C) |
| Color | Yellow → tan → cinnamon → medium brown |
| Aroma | Bread → toast → caramel → chocolate |
| Bean state | Still endothermic; Maillard reaction building complexity |

**Watch for:** Steady color darkening and aroma progression. This phase builds sweetness and aromatic depth.
**Defect risk:** Abbreviated = thin, aggressively acidic cup.

---

### Phase 3 — Development (15–25% of total roast time)
| | Detail |
|---|---|
| Starts at | First crack (~385–400°F / 196–204°C) |
| Bean state | Exothermic (releases heat); oils migrating; flavor compounds forming fast |
| Second crack | ~428°F (220°C) — pyrolysis; specialty roasters usually stop before this |

**First crack:** Sounds like light popcorn popping. Rolls over 1–3 minutes. Has a clear start, rolling middle, and end.
**Second crack:** Faster, hissing, crinkling-paper sound. Signals roast is entering dark territory.

## Roast Level Reference

| Target | Stop At | Cup Character | Weight Loss |
|---|---|---|---|
| Light | 30–60 sec after FC *starts* | Fruity, floral, high acidity, light body | 12–14% |
| Medium-Light | FC fully complete | Balanced acidity, emerging sweetness | 14–16% |
| Medium | 1–2 min after FC ends | Sweet, caramel, balanced, medium body | 16–18% |
| Medium-Dark | Approaching second crack | Bittersweet, full body, low acidity | 18–20% |
| Dark | Into/past second crack | Smoky, bitter, oily, roast-dominant | 20%+ |

**Weight loss formula:** (green_g − roasted_g) ÷ green_g × 100

## What to Record During the Roast

| Moment | Record |
|---|---|
| Before charging | Green weight, initial temp setting, ambient temp |
| ~7–9 min | Time when beans turn fully yellow |
| First pop heard | First crack onset time |
| Pops taper off | First crack end time |
| Drop | Drop time; note color and aroma |
| Any temp change | Elapsed time, new temp, and reason |

---

## Flavor Defect Diagnostics

| Cup tastes like | Likely cause | Fix next roast |
|---|---|---|
| Sour, grassy, harsh | Underdeveloped (development too short) | +20–30 sec after FC end |
| Flat, papery, dull | Baked (drying too slow) | More heat in drying; don't let momentum stall |
| Thin, aggressively acidic | Maillard phase too brief | Slow the browning phase |
| Bitter, ashy | Overdeveloped or past second crack | Drop earlier |
| Sweet, balanced, complex | Executed well | Replicate exactly — write down every setting |

---

## Rest & Cupping

- Minimum rest: **24 hours** before brewing
- Best window: **48–72 hours** for most roast levels
- Cupping protocol: 8g coarsely ground, 150mL water at 93°C (200°F), 4 minutes, break crust, skim, taste
- Rate: acidity (1–5), sweetness (1–5), body (1–5), finish, overall (1–10)
